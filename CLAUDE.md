# Look — инструкции для Claude

Look — приложение-стилист: гардероб, автоподбор образов, лента с реферальными ссылками.
`mobile/` — Expo / React Native (Expo Router), `backend/` — FastAPI.

## Как со мной работать

- Не задавай уточняющих вопросов. Принимай разумные решения сам и кратко перечисляй допущения в конце.
- Отвечай по-русски, коротко и по делу; в конце — что сделано, что проверено и чего проверить не удалось.
- Не останавливайся на подтверждениях по мелочам: правки файлов и обычные команды проекта выполняй сразу.
  Спрашивай только про необратимое и наружное: `git push`, удаление данных, публикация.

## Бэкенд (`backend/`)

Слои, зависимости только внутрь: `api` → `application` → `domain`; `infrastructure` реализует порты `application`.

- `domain/` — сущности и правила (в том числе движок подбора образов). Без фреймворков и БД.
- `application/` — **use cases** (один класс на операцию, метод `execute`), порты (`ports.py`: репозитории,
  `UnitOfWork`, внешние сервисы), ошибки. Знает про HTTP не больше, чем про SQL.
- `infrastructure/` — SQLAlchemy-**репозитории** и `UnitOfWork`, Open-Meteo, файловое хранилище, часы, хэши.
- `api/` — тонкие роутеры: разобрать запрос, вызвать use case, отдать ответ. Сборка зависимостей — `api/container.py`.
- Данные читает и пишет только репозиторий через `UnitOfWork`; use case не обращается к SQLAlchemy напрямую.
- Новая функциональность = новый use case + метод(ы) репозитория при необходимости + роутер.

### Тесты — по AAA

Каждый тест разбит на явные секции `# Arrange` / `# Act` / `# Assert`, один тест — одно поведение.

- Если подготовку целиком задают фикстуры или параметры теста, секция так и называется:
  `# Arrange: состояние задают фикстуры (client, user)`.
- Для проверки исключений Act и Assert — один оператор `pytest.raises`: секция `# Act / Assert`.
- Слои тестируются раздельно: `tests/domain` (чистые функции), `tests/application` (use cases на подделках
  из `tests/fakes.py`), `tests/infrastructure` (контрактные тесты репозиториев гоняются и на подделке, и на SQLite;
  адаптеры — на подставном HTTP), `tests/api` (сквозные, через `TestClient`).
- Время подставляется (`FrozenClock`), внешние сервисы — подделки; тесты не ходят в сеть.
- Проверка перед сдачей: `cd backend && uv run ruff check . && uv run pytest` (покрытие держим на 100%).

## Мобильное приложение (`mobile/`)

- Перед кодом, затрагивающим API Expo/React Native, свериться с документацией нужной версии SDK (см. `mobile/AGENTS.md`).
- Перед сдачей: `cd mobile && npx tsc --noEmit && npx expo lint`.
- Зависимости ставить только через `npx expo install`.
